Chttps://www.gutenberg.org/cache/epub/1524/pg1524.txtleaning & tokenization decisions for hamlet.txt
================================================

Source file:   hamlet.txt (Project Gutenberg eBook of Hamlet)
Output file:   hamlet_tokens.txt (original file left untouched)

1. Cleaning scope
   - Remove Project Gutenberg boilerplate: everything from the
     "*** START OF THE PROJECT GUTENBERG EBOOK HAMLET ***" marker to the
     "*** END OF THE PROJECT GUTENBERG EBOOK HAMLET ***" marker
     (license header, credits, release info, full license footer).
   - Remove stage directions: all [_ ... _] markers, including inline
     ones (e.g. [_Aside._]) and multi-line ones.
   - NOT removed (kept as-is):
       * front matter inside the markers (title, Contents,
         Dramatis Personae)
       * speaker names (e.g. HAMLET.)
       * line breaks / original verse lineation
       * punctuation attached to words (e.g. "HAMLET," "question,")

2. Tokenization
   - Whitespace split: tokens are separated on spaces/newlines only,
     punctuation stays attached to the word it follows.

3. Casing
   - Case preserved: "HAMLET" and "Hamlet" remain distinct.

4. Output format
   - One token per line, plain UTF-8 .txt file.

5. Result
   - 31,502 tokens total, 7,556 unique.

6. Tokenization v2 (clean.go)
   Source file:   hamlet_tokens.txt (the already cleaned file above)
   Output file:   hamlet_clean_tokens.txt (regenerated on every run)

   The v1 tokenizer split on whitespace only, so "KING," and "KING" and
   "king" were three unrelated vocabulary entries. v2 fixes that:
   - Lowercase everything.
   - Normalize punctuation/encoding: ’ ‘ -> ', — – -> -, æ -> ae,
     à -> a, "&c" -> "etc".
   - Split punctuation into its own tokens; a token is either a word
     ([a-z0-9]+, with apostrophes kept inside, so "don't" and
     "polonius's" stay whole) or a single mark from . , ; : ! ? & " ( ) [ ] -
   - Underscores are dropped, so leftover stage-direction markers such as
     "_Hic" and "ubique?_" become plain words.
   - Still: speaker names stay, lineation/verse breaks are lost to the
     join, and punctuation remains part of the sequence.

   Result: 39,318 tokens total, 4,755 unique (down from 7,556 unique).
   Splitting punctuation raises the token count but many words are now
   shared instead of fragmented, so each word gets more training examples.
